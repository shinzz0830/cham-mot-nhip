# Chậm một nhịp

Trang khảo sát tiếng Việt về FOMO, mua sắm trực tuyến và hình thức mua trước trả sau. Biểu mẫu Google Forms được nhúng để câu trả lời tiếp tục được ghi vào form hiện có.

## Chạy trên máy

Mở `index.html` trong trình duyệt hoặc chạy `python -m http.server 8000` trong thư mục dự án rồi mở `http://localhost:8000`.

## Chia sẻ công khai bằng GitHub Pages

1. Tạo một repository GitHub mới và tải các file trong thư mục này lên.
2. Trong repository, mở **Settings → Pages**.
3. Ở **Build and deployment**, chọn **Deploy from a branch**, nhánh `main` và thư mục `/(root)`, rồi bấm **Save**.
4. Chờ GitHub Pages xuất bản; link công khai sẽ hiện trong trang Settings → Pages.

Các phản hồi được lưu bởi Google Forms. Hãy kiểm tra form vẫn đang nhận câu trả lời và cho phép người tham gia truy cập trước khi chia sẻ trang.
